
英文單字複習網站 v1
====================

使用方式：
1. 解壓縮後直接雙擊 index.html。
2. 建議使用 Chrome 或 Edge。
3. 第一次使用可進入「單字管理」→「載入範例單字」。
4. 可新增 Week、英文、中文、例句。
5. 「開始複習」可以：
   - 單字卡
   - 四選一
   - 英文拼字
   - 聽寫
   - 英文發音
6. 學習紀錄會儲存在目前瀏覽器的 LocalStorage。

注意：
- 目前是單機版，不需要伺服器或資料庫。
- 換電腦/清除瀏覽器網站資料後，LocalStorage 資料不會跟著過去。
- 下一版可以再加入 Excel/CSV 匯入、匯出、家長後台、登入、雲端資料庫與 AI 自動產生單字。
